## Что это

Браузерный low-poly хоррор **«ТИШЕ / HUSH»** про эхолокацию: свет гаснет, и единственный способ
что-то увидеть — издать звук (микрофон / щелчок / хлопок). Цель: запустить пять генераторов,
собрать УАЗ и уехать. Онлайн до 4 игроков, голос по близости через WebRTC, Тень подражает голосам игроков.

- Репозиторий: `SanLARAN/pinterest`, игра: https://sanlaran.github.io/pinterest/
- Стек: **Vite 8 + three.js 0.186**, vanilla ES-модули. Никакого React, никакого игрового движка.
- **Ассетов нет.** Геометрия, текстуры, все звуки синтезируются кодом (WebAudio). Исключение — два
  webfont'а (`@fontsource/jetbrains-mono`, `@fontsource/rubik-wet-paint`).
- Текущая версия игры в README: **2.1** «Смена затянулась», сетевой протокол **14**. `package.json`
  version намеренно остаётся `1.0.0` — версию игры ведёт README и `src/ui/news.js`, не npm.
- Язык: интерфейс RU (по умолчанию) и EN; код и комментарии — английский; коммиты — английский.

## Команды

```bash
npm ci                 # чистая установка (нужен Node 22+)
npm run dev            # http://localhost:5173 (уже с --host 0.0.0.0)
npm test               # node --test tests/*.test.mjs — сейчас 133 теста, все проходят (~6 с)
npm run build          # dist/ (в .gitignore)
npm run build:pages    # собрать play/ — ЭТО КОММИТИТСЯ, см. ниже
npm run preview
```

Проверка перед коммитом, минимум: `npm test && npm run build`.
Если менялись исходники — ещё `npm run build:pages` и закоммитить `play/` (CI падает, если `play/`
не совпадает с исходниками байт в байт).

## Правила, которые нельзя нарушать

1. **Баланс — только в `src/core/config.js`.** Не разбрасывать магические числа по геймплею.
2. **Строки — только через `src/core/i18n.js`** (`t('key')`), обе локали RU+EN. Никакого текста в вёрстке.
3. **Хост авторитетен.** Всё, что приходит по сети, валидируется (`clean*`-функции, проверки в
   `netsync`/`coop`/`outfit`). Клиент не диктует состояние: предметы, урон, шкафы, машина — за хостом.
4. **Меняешь сетевой протокол — поднимай `PROTOCOL` в `src/net/net.js` и допиши строку в его
   комментарии.** Старые клиенты должны отваливаться, а не жить в полусломанной игре.
5. **Тач-паритет.** У каждого действия есть клавиша и тач-кнопка; на таче рюкзак — плоская сетка.
6. **Никаких новых зависимостей без причины.** Проект гордится тем, что всё синтезируется кодом.
7. **Доступность:** скримеры имеют «мягкий» режим (`настройки`), не ломать его.
8. **Приватность звука:** фразы Тени живут только в RAM сессии, в localStorage и на сервер не пишутся.
   Это обещание в README — не нарушать.
9. **README — обещание игроку.** Новая механика ⇒ абзац в README + запись в `src/ui/news.js` (RU+EN,
   дата, версия) + при необходимости бамп версии в README.
10. Коммиты: `feat(2.1): the long shift - ...` — английский, строчными, с версией в скобках.
    Один коммит — одна законченная фича.

## Подводные камни (проверено на практике)

- **`play/` — собранная копия, лежит в git.** Забыл `npm run build:pages` → CI «Prebuilt ./play/ is
  up to date» краснеет. Собрано всё детерминированно: имя бандла совпадает (`index-BtcYlHmO.js`).
- **Workflow `Pages (HUSH)`** (`.github/workflows/pages.yml`) триггерится только на
  `main` и `arena/428824a1-pinterest`. На других ветках (включая текущую) CI не запускается —
  это не поломка, а забытый список веток; при желании расширить до `arena/**`.
- **Микрофон только по `https://` или `localhost`.** В iframe браузер часто его блокирует —
  игру надо открывать в отдельной вкладке. Без микрофона всё играется клавиатурой и тачем.
- **Тесты — чистый Node, без DOM.** Они импортируют модули напрямую и подсовывают фейки:
  `Object.create(Backpack.prototype)`, фейковый `AudioContext` (`createBuffer`), фейковый `game`.
  Поэтому нельзя тянуть в тестируемые модули `document`/`window` на этапе импорта.
- **Бандл ~1.7 МБ одним куском** (vite ругается на chunk > 1500 kB). Это осознанно: игра грузится
  один раз. Код-сплиттинг не делать без запроса.
- **Отладка — query-флаги:** `?night`, `?t=500`, `?fps`, `?nomic`, `?speed=2`, `?sfx`, `?autostart`,
  `?room=КОД`, `?net=nostr|torrent`, `?relays=ws://…`. Не изобретать новые, пока хватает этих.
- **Облако (Supabase):** в `.env` только публичные `VITE_SUPABASE_URL` / `VITE_SUPABASE_PUBLISHABLE_KEY`.
  `service_role` / `sb_secret` в клиент не попадают никогда.
- **Смоук-тесты сети** (`tests/online-smoke.mjs`, `tests/cloud-live.mjs`) — только в CI, им нужны
  живые Nostr-релеи и headless Chrome; локально не запускать «на всякий случай».

## Как продолжать работу

Первое сообщение в новом чате (скопировать целиком):

```
Продолжаем разработку игры «ТИШЕ / HUSH» в этом репозитории (ветка arena/b96c115e-pinterest).
Прочитай AGENTS.md и docs/SESSION_LOG.md, затем README.md (раздел «Устройство») и src/core/config.js.
Кратко перескажи мне состояние проекта и предложи, с чего продолжим.
Правила: npm test и npm run build должны быть зелёными; если менялись исходники — npm run build:pages и коммит play/.
```

В конце крупной сессии — дописать 5–10 строк в `docs/SESSION_LOG.md`: что сделано, какие решения
приняты и почему, что осталось. Так знания не зависят от длины чата.
