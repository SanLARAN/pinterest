# AGENTS.md

Этот файл читает любой новый чат/агент, прежде чем что-то менять. Он короткий; вся суть — в
[`docs/CONTEXT.md`](docs/CONTEXT.md).

**Проект:** браузерный эхолокационный хоррор «ТИШЕ / HUSH» — Three.js, Vite, без ассетов (вся геометрия и звук
синтезируются в коде), RU/EN, одиночная игра и кооп до 4 игроков.

## Порядок чтения

1. `docs/CONTEXT.md` — механики с числами, стиль, архитектура, конвенции, грабли. **Главный документ.**
2. `README.md` — то же для игрока: как играть, что в каком обновлении, карта модулей.
3. `src/core/config.js` — весь баланс; если документ и код расходятся, прав код.
4. Перед правкой конкретной системы — её файл из карты в `docs/CONTEXT.md` §5.

## Жёсткие правила

- **Стиль не обсуждается.** Палитра — токены `:root` в `src/style.css` (`--ash`, `--bone`, `--red`, `--blood`,
  `--amber`, `--panel`). Шрифты: JetBrains Mono везде, Rubik Wet Paint только для заголовков ужаса. Никаких
  внешних моделей/текстур/иконок — только `MeshBuilder` + `KIND` и шейдеры.
- **Свет = проявление.** Новый объект мира идёт через `world/builder.js`, а не своим материалом.
- **Любая строка — через `t()`** в `src/core/i18n.js`, сразу `ru` **и** `en`. Хардкод строк — баг.
- **Раунды буквами:** 2.1a, 2.1b, … 2.1x. Раунд закрыт, когда есть код + тесты + запись в `README.md` +
  запись в `src/ui/news.js` (ru и en) + коммит.
- **Коммит** объясняет причину и числа, а не «fix». Пуш — в текущую ветку сессии, PR не нужен, если не просили.
- **Деплой** — тег `arena/liveN` → workflow `Pages (HUSH)` собирает `play/`. `play/` руками не править.
  Настольная сборка `.exe` — тот же тег → workflow `Desktop (HUSH)`; оболочка в `electron/`, см. `docs/DESKTOP.md`.
- **Осторожно:** `src/audio/audio.js` (3.8k строк), `game/game.js` (2.4k), `ui/garage.js` (2.2k) — большие
  и связанные; менять точечно и проверять тестами.
- В коопе **хост авторитетен** (твари, подборы, шкафы, ворота). Не переносить решения на гостя.

## Проверка

```bash
npm install
npm test            # node:test, 49 файлов, 437 тестов (3.0v) — все должны быть зелёными
npm run dev         # http://localhost:5173
npm run build:pages # сборка в play/ — без неё деплой покажет старую версию
```

- Менял картинку — **скриншот в кадре**, а не описание шейдера.
- Headless-браузер (SwiftShader) даёт ~4 fps: не ждать таймером, а прыгать по состоянию
  (`window.__hush.opening.seek(t)`, `game.startDawn()`) и шагать кадры вручную.
- Полезные URL: `?nointro`, `?night`, `?t=500`, `?nomic`, `?fps`, `?sfx`, `?speed=2`, `?room=КОД`.
- Ловушки и рецепты харнесса — `docs/CONTEXT.md` §6.

## Чего не делать

- Не переписывать сонар-шейдер, лес и сетевой протокол «для красоты».
- Не добавлять зависимости без нужды: проект намеренно почти без библиотек.
- Не коммитить `node_modules`, `.env`, скриншоты и временные скрипты.
