# ТИШЕ / HUSH

**Low-poly эхолокационный хоррор в браузере.** Ты слеп в огромном ночном лесу. Единственный способ что-то увидеть — издать звук: голос в микрофон, щелчок языком, хлопок. Волна расходится от тебя и на секунды проявляет деревья, камни… и **их**. Продержись до рассвета — **30 минут** — и не закричи.

> Играй в наушниках. Звук — твои глаза.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run preview    # просмотр сборки
```

Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16+). Микрофон работает только по `https://` или на `localhost`. Во встроенном окне (iframe) браузер часто блокирует микрофон — открой игру в отдельной вкладке. Без микрофона всё работает от клавиатуры и тача.

## Как играть

- **Звук = зрение.** Чем громче звук, тем дальше видно: тихий звук подсвечивает ~15 м, крик — ~65 м.
- **Но они слышат так же далеко.** Твари идут туда, где был звук, а не туда, где ты сейчас. Издал звук — уходи.
- **Крик (кольцо стало красным) — мгновенная охота.** Охотник визжит, и лес наливается красным.
- **Замри.** Если тварь обнюхивает место рядом, а ты не двигаешься и молчишь, она тебя не найдёт.
- **Шаги тоже шумят:** бег громкий, крадучись — почти беззвучно. Удар о дерево слышен. Если задохнёшься после бега, тяжёлое дыхание тоже слышно.
- **Камни** отвлекают тварей и подсвечивают место падения. Если ты какое-то время молчал, камень может сорвать погоню.
- Монстров никогда не видно напрямую — только их **эхо-отпечаток** (чёрный силуэт в красном контуре) в момент, когда волна до них дошла. Ты видишь, где они *были*.
- **Глаза в темноте.** Если тварь смотрит на тебя, в темноте на миг вспыхивают её глаза — чем она заинтересованнее, тем чаще. Но лес показывает и глаза, которые никому не принадлежат, и силуэты на краю зрения.

### Интерфейс

Его почти нет — темнота и есть интерфейс.

- **Точка в центре** и **кольцо вокруг неё** — твоя громкость. Красный пунктир — граница крика: кольцо дошло до него — тебя услышат все.
- **Время и счёт** всплывают на старте и каждую минуту; в любой момент — **Tab** (на таче — тап по верху экрана).
- Тонкая линия по верхнему краю экрана медленно заполняется к рассвету.
- Выносливость и камни появляются под точкой, только когда меняются.
- Радар-миникарта выключен по умолчанию: *Настройки → Радар (подсказка)*.

### Очки

| | |
|---|---|
| Выживание | 10/сек × множитель опасности (+0.5 каждые 5 минут) |
| Янтарный осколок | 250 × множитель (+1 камень) |
| «Впритык» — тварь прошла в паре метров и не заметила | 300 × множитель |
| Оторвался от погони | 500 × множитель |
| Рассвет (30:00) | +25 000 |

Таблица рекордов (топ-10) хранится локально в браузере.

### Управление

| Действие | Клавиатура / мышь | Тач |
|---|---|---|
| Движение | WASD (стрелки ↑↓) | левый стик (до упора — бег) |
| Обзор | мышь (клик — захват курсора), ←→ / Q E | правая половина экрана |
| Эхо | ПРОБЕЛ / ЛКМ: тап — щелчок, удерживай — громче | кнопка ЭХО |
| Микрофон | говори, щёлкай, хлопай · M — вкл/выкл | в меню / настройках |
| Время, счёт, камни | Tab (удерживать) | тап по верху экрана |
| Камень | ПКМ / F | КАМЕНЬ |
| Бег / красться | Shift / C | стик до упора / ТИХО |
| Пауза | Esc / P | ⏸ |
| Заново | R / Enter (на экране смерти) | тап |

### Настройки

Громкость, чувствительность мыши и микрофона, инверсия Y, эхо голоса, радар, **мягкие скримеры** (без стробоскопа, вспышек и мерцания), качество графики (авто — динамическое разрешение), язык RU/EN.

## Устройство

Vite + three.js, без игровых движков и без ассетов: геометрия, звуки и шрифты (кроме двух webfont'ов) генерируются кодом.

```
src/
  core/     config.js (весь баланс), rng.js (seeded RNG + simplex), i18n.js, storage.js
  world/    процедурный лес 600×600 м: рельеф, ~6900 деревьев, 12 локаций (лагерь, хижины,
            вышки, каменные круги, обломки, кладбища, озеро), коллизии
  render/   sonar.js — шейдер «сонара» (зернистые рёбра low-poly + волны звука), pulses.js — волны,
            ghosts.js — эхо-отпечатки монстров (тёмный силуэт, дрожь, разрывы), eyes.js — глаза
            в темноте, particles.js, post.js — bloom, пепельная цветокоррекция (живёт только
            красный), туннельная виньетка, зерно, мерцание, «плёнка» при опасности
  audio/    audio.js — процедурный WebAudio (щелчки, эхо-отзвуки, монстры, эмбиент, скримеры),
            mic.js — микрофон: шумовой порог, детектор звука, эхо голоса, «мимик»
  game/     game.js — правила, директор, скримеры; dread.js — глаза, галлюцинации, мерцание;
            monsters.js — модели и ИИ; player, shards, stones
  input/    клавиатура (по e.code — любая раскладка), мышь с pointer lock, тач
  ui/       минимальный HUD, радар (опционально), меню
```

Отладка: `?fps` — счётчик FPS, `?nomic` — без микрофона, `?t=1700` — начать с 28:20, `?speed=2` — ускорить время, `?autostart`.
