# АРКОН — симулятор держав

Интерактивный стратегический интерфейс на русском языке: создайте свою державу, управляйте экономикой, дипломатией, армиями и исследованиями, а затем проведите её через эпохи от средневековья к современности.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.
