# Pinwave — Pinterest, по-новому

Легкое расширение Chrome/Chromium на Manifest V3, которое меняет внешний вид Pinterest и добавляет быстрые режимы просмотра.

## Возможности

- **Чёрная тема** — глубокий чёрный фон и минималистичные поверхности без лишних теней.
- **Плотная сетка** — уменьшает промежутки между пинами.
- **Режим фокуса** — приглушает боковую навигацию, пока вы не наведете на нее курсор.
- **Появление пинов** — новые карточки плавно проявляются при прокрутке ленты вниз.
- Настройки синхронизируются через `chrome.storage.sync` и применяются сразу. Анимация использует `IntersectionObserver` и отключается при системной настройке уменьшения движения.

## Установка для разработки

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку.
4. Откройте или обновите `https://www.pinterest.com/` или `https://ru.pinterest.com/`, затем нажмите иконку Pinwave.

Стили Pinterest иногда меняются. Если сайт обновит свои селекторы, соответствующие правила в `styles.css` можно будет скорректировать. Расширение не обращается к сторонним серверам и не собирает данные.
