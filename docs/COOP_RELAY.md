# Игра с другом издалека — ретранслятор (TURN)

Игроки соединяются напрямую (WebRTC). Обычно этого хватает, но если у друга мобильный интернет, «серый» IP у
провайдера (CGNAT) или строгий рабочий Wi-Fi, прямое соединение не пробивается — в лобби он навсегда «ищет хоста».
Расстояние само по себе не мешает; мешает сеть. Решение — ретранслятор (TURN): он просто пересылает зашифрованные
пакеты, когда напрямую не выходит.

Код готов (3.1e): игра перед входом в комнату спрашивает у своей функции Supabase `hush-turn` логин/пароль от
TURN и подключается через него, только если напрямую нельзя. В лобби видно:
«ретранслятор есть — подключится и издалека» или «без ретранслятора — только прямое соединение».

## Что нужно сделать владельцу (≈5 минут, бесплатно): ExpressTURN

Функция `hush-turn` уже развёрнута в проекте `ppylutuhhmvhgqqqnldm`. Ей не хватает только логина от ретранслятора.

1. **ExpressTURN:** https://www.expressturn.com → регистрация по почте (карта не нужна) → в личном кабинете
   бесплатный тариф (1000 ГБ в месяц). Там будут **сервер** (вида `relay1.expressturn.com:3478`), **username**
   и **password**. Регион сервера выбери посередине между вами (например, Европа).
2. **Supabase:** Dashboard → Edge Functions → **Secrets** → добавить три:
   - `TURN_URLS` = `turn:relay1.expressturn.com:3478,turn:relay1.expressturn.com:3478?transport=tcp`
     (подставь свой сервер; второй адрес — через TCP, для сетей, где UDP закрыт);
   - `TURN_USERNAME` = username;
   - `TURN_CREDENTIAL` = password.
3. Проверка: открыть https://ppylutuhhmvhgqqqnldm.supabase.co/functions/v1/hush-turn — должно быть
   `"configured":true`. В лобби игры появится «ретранслятор есть — подключится и издалека».

Новый релиз игры для этого не нужен: функция читает секреты при каждом запросе. Логин ретранслятора виден любому,
кто откроет адрес функции, — для бесплатного тарифа это нормально (худшее — кто-то потратит часть лимита); если
это станет проблемой, достаточно сменить пароль в ExpressTURN и в секретах.

Другие варианты, без изменений в коде: свой coturn на VPS (те же три секрета) или Cloudflare Realtime TURN
(`CF_TURN_KEY_ID`, `CF_TURN_API_TOKEN` — используется, только если трёх секретов выше нет).

## Что ещё может мешать

- **Сигнальные сети** (как игроки находят друг друга): Nostr-реле и BitTorrent-трекеры, по нескольку сразу.
  Если в стране друга заблокированы и те, и другие, в лобби будет «реле: 0/…». Это отдельная история —
  можно добавить третий путь через Supabase Realtime.
- **Разные версии игры** — в лобби будет «другая версия игры»: обоим нужно обновиться.
