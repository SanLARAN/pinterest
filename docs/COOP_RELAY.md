# Игра с другом издалека — ретранслятор (TURN)

Игроки соединяются напрямую (WebRTC). Обычно этого хватает, но если у друга мобильный интернет, «серый» IP у
провайдера (CGNAT) или строгий рабочий Wi-Fi, прямое соединение не пробивается — в лобби он навсегда «ищет хоста».
Расстояние само по себе не мешает; мешает сеть. Решение — ретранслятор (TURN): он просто пересылает зашифрованные
пакеты, когда напрямую не выходит.

Код готов (3.1e): игра перед входом в комнату спрашивает у своей функции Supabase `hush-turn` временные
логин/пароль от TURN (на 6 часов) и подключается через него, только если напрямую нельзя. В лобби видно:
«ретранслятор есть — подключится и издалека» или «без ретранслятора — только прямое соединение».

## Что нужно сделать владельцу (≈10 минут, бесплатно)

Ретранслятор — Cloudflare Realtime TURN: **1000 ГБ в месяц бесплатно** (это сотни часов игры вчетвером).

1. **Развернуть функцию** `supabase/functions/hush-turn` в проекте `ppylutuhhmvhgqqqnldm` — или разрешить
   агенту (инструмент `deploy_edge_function`), или самому:
   `npx supabase functions deploy hush-turn --project-ref ppylutuhhmvhgqqqnldm --no-verify-jwt`
   (`--no-verify-jwt`: гости без аккаунта тоже должны получить ретранслятор).
2. **Cloudflare:** https://dash.cloudflare.com → зарегистрироваться → **Realtime** (раньше «Calls») → **TURN Server**
   → **Create** → скопировать **Turn Token ID** и **API Token**.
3. **Supabase:** Dashboard → Edge Functions → **Secrets** → добавить:
   - `CF_TURN_KEY_ID` = Turn Token ID
   - `CF_TURN_API_TOKEN` = API Token
4. Проверка: открыть https://ppylutuhhmvhgqqqnldm.supabase.co/functions/v1/hush-turn — должно быть
   `"configured":true` и список `iceServers`. В лобби игры появится «ретранслятор есть».

Новый релиз игры для этого не нужен: функция читает ключи при каждом запросе.

## Что ещё может мешать

- **Сигнальные сети** (как игроки находят друг друга): Nostr-реле и BitTorrent-трекеры, по нескольку сразу.
  Если в стране друга заблокированы и те, и другие, в лобби будет «реле: 0/…». Это отдельная история —
  можно добавить третий путь через Supabase Realtime.
- **Разные версии игры** — в лобби будет «другая версия игры»: обоим нужно обновиться.
